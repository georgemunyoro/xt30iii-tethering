What changes on the camera?
Setup temporarily exposes USB Auto and USB Fixed in place of Webcam and RAW conversion. It does not flash firmware. You select USB Fixed yourself; that saved setting has survived a normal restart and a RAW+JPEG transfer on the tested camera.
The menu patch is temporary. Permanent menu visibility, battery removal, and changing away from USB Fixed have not been validated. Keep USB Fixed selected for this workflow.

      
Mac or USB connection help
On macOS, install dependencies with the included Install Mac dependencies.command. Unlock your Mac, allow the USB accessory if asked, and quit Photos, Image Capture, and other camera apps. Only one app can use the camera at a time.
On Linux, install uv and libusb and make sure your account has access to the camera’s USB device. The utility never detaches system drivers or terminates other apps.
